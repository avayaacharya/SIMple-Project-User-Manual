Ficheiros Chave — O Que Fazem

📄 src/data/types.ts — Utilizadores & Tipos

  • Define os tipos TypeScript (User, Module, Section, TreeNode).
  • Contém o objeto USERS com todas as contas, senhas e permissões de módulos.
  • Para adicionar um utilizador: acrescente uma entrada ao objeto USERS.

📄 src/data/hr-content.ts — Módulo de Recursos Humanos

  • Exporta o objeto hrModule com a árvore de navegação e o conteúdo HTML de cada secção.
  • Cobre: Registo de Emprego, Presença (Licenças, Férias, Assiduidade, Ausências, Horas Extra), Serviço Online (Certificados).
  • Figuras reais: usa tags <figure class="doc-figure">; placeholders: <div class="figure-placeholder">.

📄 src/data/contracts-content.ts — Módulo de Contratos

  • Exporta o objeto contractsModule com a estrutura completa do módulo de gestão de contratos.
  • Cobre: Planeamento de Aquisições, Fornecedores, Registo de Contratos, Adendas, Relatórios.
  • As figuras deste módulo aguardam o PDF de referência de Contratos.

📄 src/components/ContentPanel.tsx — Renderizador

  • Renderiza o HTML de cada secção usando dangerouslySetInnerHTML.
  • A função upgradeFigures() transforma automaticamente qualquer figure-placeholder legado em blocos <figure> com imagem real, se a imagem existir em /public.
  • Inclui botão de impressão no cabeçalho de cada secção.

Como Executar / Desenvolver

  1. O portal é executado automaticamente pelo workflow configurado no Replit. Não é necessário iniciar manualmente.

  2. Para reiniciar manualmente, execute: pnpm --filter @workspace/simple-manual run dev

  3. Para verificar tipos TypeScript: pnpm --filter @workspace/simple-manual run typecheck

  4. Para adicionar conteúdo, edite hr-content.ts ou contracts-content.ts — o Vite atualiza a página automaticamente (HMR).

  5. Para adicionar imagens, copie os ficheiros para artifacts/simple-manual/public/ e referencie-os com /nome-ficheiro.jpg no conteúdo HTML.

Importante: Não execute pnpm run dev na raiz do monorepo. Use sempre o filtro --filter @workspace/simple-manual ou o workflow do Replit.

Como Fazer Alterações Comuns

Adicionar um novo utilizador

  • Abra src/data/types.ts
  • Acrescente uma entrada ao objeto USERS: 'EMP005': { password: 'senha', name: 'Nome', modules: ['hr'] }

Adicionar ou editar conteúdo de uma secção

  • Abra src/data/hr-content.ts ou contracts-content.ts
  • Localize a secção pelo seu ID (e.g. hr-2-1) e edite o campo content (HTML em template literal)
  • Use <figure class="doc-figure"> para imagens e <div class="note-box"> para notas de aviso

Adicionar uma nova secção ao módulo

  • Acrescente um objeto à propriedade sections com um ID único
  • Adicione o nó correspondente ao array tree do mesmo módulo para que apareça na navegação lateral

Substituir uma figura placeholder por imagem real

  • Copie a imagem para artifacts/simple-manual/public/
  • Substitua o <div class="figure-placeholder">...</div> por um bloco <figure class="doc-figure"><img src="/ficheiro.jpg" .../><figcaption>...</figcaption></figure>
